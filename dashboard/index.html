Поиск ниш YouTube

Длинные видео, малые каналы, без миллионников

Ключи YouTube API

  1. Создайте проект в Google Cloud (карта не нужна, пробный период пропустите).
  2. Включите YouTube Data API v3 (Enable).
  3. Create credentials → API key и вставьте ключ сюда.

Ключ Claude API (для разборов)

  1. Зайдите на console.anthropic.com и пополните баланс в Billing (хватит $5–10 на начало).
  2. В разделе API Keys нажмите Create Key и вставьте ключ сюда.

Настройки анализа

Что считать успехом, какие каналы малые и новые, и насколько важен каждый критерий. Изменённые поля подсвечены. После сохранения все найденные ниши пересчитаются по новым правилам. Это бесплатно: данные берутся из кэша (поиск хранится 3 дня, после этого у ниши обновится только балл по новым весам). Период и длины поиска меняют сам поиск, поэтому действуют на новые запуски и тратят квоту.

Машина сама перебирает вечнозелёные темы из каталога. Сначала делает быструю разведку многих тем, потом полный анализ лучших, а подниши лучших откладывает на следующий запуск. С каждым запуском она уходит глубже.

Можно писать по-русски, тема переведётся на язык каждого рынка. Пусто: возьмём стартовые темы.
