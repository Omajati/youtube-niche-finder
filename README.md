# YouTube Niche Finder

Ищет перспективные ниши для длинных роликов (от 8 минут) на YouTube: где малые каналы
набирают просмотров кратно больше, чем у них подписчиков, новые каналы быстро растут,
а миллионников почти нет. Рынки: английский, испанский, немецкий, французский.

## Запуск

Нужен только Python 3.9+, внешние библиотеки не требуются.

1. Скопируйте `.env.example` в `.env` и впишите ключи YouTube Data API v3 в `YOUTUBE_API_KEYS`
   (до 4 штук через запятую). Файл `.env` не попадает в git.
2. Запустите дашборд:
   ```
   python app.py
   ```
   Откроется http://localhost:8000. Слева впишите темы и языки и нажмите «Запустить анализ».

Можно и из командной строки:
```
python cli.py "unsolved mysteries" --langs en --expand 3 --max 8
python cli.py --langs es --expand 2      # автопоиск от стартовых тем
```

### Как получить ключ

Google Cloud Console → новый проект → APIs & Services → Library → «YouTube Data API v3» → Enable →
Credentials → Create credentials → API key. Повторите в каждом Google-аккаунте.

## Как ищутся ниши

1. Берём темы (ваши или стартовые для каждого языка: загадки, странные истории, забытая история…).
2. Расширяем каждую тему подсказками поиска YouTube (бесплатно, квоту не тратит).
3. Для каждой ниши: два поиска (ролики 4–20 минут и длиннее 20 минут, по 50 штук за последние 180 дней),
   затем статистика роликов и каналов.
4. Отбрасываем ролики короче 8 минут и ролики на другом языке (по указанному языку видео, а если он
   не указан, по письменности и пометкам вроде «Hindi Documentary»).
5. Теги успешных роликов показываются на дашборде как «похожие подниши»: клик добавляет тему
   в следующий запуск.

## Оценка ниши (0–100)

| Критерий | Вес | Что считается |
|---|---|---|
| Просмотры ≫ подписчики | 35% | Медиана «просмотры / подписчики» у роликов каналов до 200K. 0.3× → 0, 10× → максимум |
| Новые каналы растут | 25% | Каналы младше 90 дней в выдаче, у которых есть ролик от 10K просмотров (3 таких = максимум) |
| Мало миллионников | 20% | Доля каналов от 1M подписчиков. 0% → максимум, 40% и больше → 0 |
| Стабильный спрос | 10% | Просмотры не держатся на одном ролике, и несколько малых каналов имеют ролики ≥ 1× |
| Формат и нагрузка | 10% | Длина успешных роликов и частота загрузок их каналов (≤1 в неделю = легче зайти) |

Пометка «мало данных» означает, что в выдаче меньше 10 длинных роликов или меньше 5 роликов малых каналов.

## Квота

Каждый ключ даёт 10 000 единиц в день. Анализ одной ниши стоит около 204 единиц
(два поиска по 100 + статистика 4), то есть примерно 49 ниш в день на ключ и около 195 на четыре ключа.
Чтобы тратить вдвое меньше, впишите в `.env` строку `SEARCH_DURATIONS=long`: тогда ищутся только ролики
длиннее 20 минут.

- Ответы API кэшируются в `data/cache/` (поиск на 3 дня), повторный анализ той же ниши бесплатен.
- Когда ключ упирается в квоту, инструмент переключается на следующий. Если закончились все,
  анализ останавливается, уже готовые результаты сохраняются.
- Расход за сегодня по каждому ключу виден на дашборде.
